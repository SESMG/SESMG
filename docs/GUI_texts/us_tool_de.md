# Urban District Upscaling-Tool
Durch die Nutzung des Urban District Upscaling-Tools wird automatisch ein Modell erstellt, das die in der folgenden Abbildung dargestellten Komponenten enthält. Das Modell ist unterteilt in Komponenten des Hauptsystems, die nur einmalig erstellt werden, und Komponenten der Teilsysteme, die für jedes einzelne Teilsystem angelegt werden. Eine detaillierte Beschreibung des Systems finden Sie hier:
[Urban District Upscaling Tool - Dokumentation](https://spreadsheet-energy-system-model-generator.readthedocs.io/en/latest/01.04.00_urban_district_upscaling.html).
